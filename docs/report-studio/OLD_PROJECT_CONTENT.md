## 7. 校验规则

在生成正式报告正文和导出 Word 前，必须检查：

### 7.1 地名校验

当前项目不是绵阳时，检查以下关键词是否出现在正式正文中：

```javascript
const OLD_GEOGRAPHIC_KEYWORDS = [
  '绵阳', '科技城新区', '虹苑路社区', '金祥寺社区', '张家营村',
  '普明街道', '永兴镇', '安昌河', '华瑞汽车厂', '路南工业园',
  '青片小区', '高新假日小区', '文泉凯旋小区', '太阳岛小区',
  '广夏城', '广厦城', '玻钢厂'
];
```

### 7.2 年份校验

- 政策文件年份保留
- 报告年份必须匹配 `report.year`
- 数据年份必须匹配 `data.statisticalYear`
- 建设时序必须匹配项目实际规划

### 7.3 单位校验

- 旧单位名称不得出现
- 替换为 `report.organizer` 或人工编辑内容

### 7.4 数字校验

- 正文数字必须存在于 `allowedFacts` 或计算结果中
- 无来源数字阻止正式版导出
