# 报告版本快照接口

## 原则

- 动态报告只读取正式问题库，不读取尚未人工确认的 AI 候选问题。
- 每次生成报告都创建一个新版本，不覆盖旧版本。
- 报告保存完整 JSON 数据快照和来源数据编号。
- 后续项目、照片、问题或指标变化不会修改旧报告。
- PDF 文件以后从指定版本快照生成，避免导出时数据漂移。

## 生成报告版本

```http
POST /api/reports/generate
Content-Type: application/json
```

```json
{
  "projectId": "1784512879166",
  "generatedBy": "报告生成人员"
}
```

项目必须至少有一条人工确认的正式问题。

## 查询项目报告版本

```http
GET /api/reports?projectId={projectId}
```

版本按从新到旧排列。

## 查询指定版本

```http
GET /api/reports/{reportId}
```

## 快照内容

- 项目名称、位置、类型、范围和面积。
- 小区数、楼栋数和户数。
- 照片归档数量。
- 已归档分析批次数量。
- 正式问题总数和风险分布。
- 各指标库大类的问题数量。
- 正式问题明细。
- 社区／街区分析结果。
- 本版本使用的项目、小区、楼栋、照片、分析批次和正式问题编号。
- 生成时间、数据截止时间和生成人员。
