## 运行方式

### 单文件离线版

直接用Chrome或Edge打开：

```text
preview-v9.1.html
```

CSS、JavaScript、23个woff2字体和11张运行图片均已内嵌，可断网运行；运行时外部HTTP/HTTPS资源为0。

### 工程版

在本目录启动任意本地静态服务器，然后打开`index-v9.1.html`。例如：

```text
python -m http.server 8000
```

工程版只读取本地`assets/`资源，不使用在线字体、CDN、在线地图、外部API或后台服务。

### 重建单文件

```text
node build-v9.1.mjs
```

构建脚本使用函数式替换器，生成`preview-v9.1.html`；工程JavaScript与单文件还原JavaScript一致。
