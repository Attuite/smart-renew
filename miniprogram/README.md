# 智更现场采集小程序

该目录是“智更平台”的原生微信小程序采集端，只负责：

- 选择小区和楼栋；
- 填写或确认总户数；
- 选择住区问题类型；
- 拍摄、暂存并上传多张照片。

## 开始使用

1. 在微信公众平台注册小程序并取得 AppID。
2. 修改 `project.config.json` 中的 `appid`。
3. 修改 `config.js`：
   - `apiBaseUrl`：智更平台 CloudBase HTTP 服务地址；
   - `projectId`：可选的固定数据项目 ID。留空时自动汇总全部项目的小区，现场人员仍然只需选择小区。
4. 在微信公众平台配置 `request` 合法域名。
5. 用微信开发者工具导入当前 `miniprogram` 目录。

## 上传流程

1. 创建带防重编号的现场采集任务；
2. 照片压缩后逐张上传；
3. 全部成功后标记任务完成；
4. 上传失败时保留当前表单和本地照片，可点击重试。

正式发布前还需要完成小程序主体认证、备案、隐私保护指引和真机测试。
